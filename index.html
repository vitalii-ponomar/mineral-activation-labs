Why this matters now

More mineral streams are available. Far fewer are ready for real deployment.

The bottleneck is rarely a lack of data. It is poor pathway selection, weak feedstock logic, and too much testing before the basic technical case is clear.

01

Feedstock realism

Mineralogy, reactive fraction, impurities, and variability set hard limits on what a material can become.

02

Processing realism

Grinding, calcination, washing, blending, and logistics can decide whether a promising result is still commercially meaningful.

03

Pathway realism

The same feedstock can be weak in one application and highly attractive in another. That choice should happen early.
